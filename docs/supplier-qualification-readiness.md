# Kitchen Electronics Factory — Supplier Qualification Readiness

> **Project Coo-Cah | AI-Powered Manufacturing Ecosystem**
> **Factory:** Coo-Cah Kitchen Electronics Factory | **Factory ID:** CCK-EL-KIT
> **Document Version:** 1.0 | **Owner:** Supply Chain Manager
> **Status:** Mobilisation Sprint — ASL framework and qualification gating

---

## 1. Purpose

This document defines the sprint work package for moving the Approved Supplier List (ASL) from static planning status to an **active qualification framework** that supports long-lead procurement preparation.

---

## 2. Sprint Objectives

| Objective | Outcome |
|-----------|---------|
| Agree qualification criteria | One standard evaluation basis across commodities |
| Prioritise critical suppliers | Long-lead and regulator-sensitive items reviewed first |
| Link qualification to evidence | No supplier treated as operationally approved without auditable evidence |

---

## 3. Qualification Gates

| Gate | Requirement | Evidence |
|------|-------------|----------|
| QG-01 | Commercial fit confirmed | Quotation / term sheet |
| QG-02 | Technical specification fit confirmed | Approved technical datasheet |
| QG-03 | Quality capability confirmed | Audit report or quality questionnaire |
| QG-04 | Regulatory / certification fit confirmed | CoC, MSDS, food-contact declaration, or equivalent |
| QG-05 | Logistics and lead time confirmed | Incoterm / transit plan / local delivery plan |

Only suppliers that pass all applicable gates may move to **operationally approved** status.

---

## 4. Critical Supplier Prioritisation

| Commodity | Priority | Reason |
|-----------|----------|--------|
| Compressors | Highest | Long lead time; refrigerator line dependency |
| Magnetrons | Highest | Long lead time; microwave line dependency |
| IGBT modules | Highest | Induction cooker dependency; allocation risk |
| R600a refrigerant | Highest | Regulated commodity; EHS dependency |
| PU foam chemicals | High | Environmental and hazardous process dependency |
| Plastics (intragroup) | High | Daily supply dependence |
| Packaging | Medium | Local supply but must support launch readiness |

---

## 6. Status Language

Use the following ASL states:

| State | Meaning |
|-------|---------|
| Planned | Supplier named in strategy but not yet qualified against sprint gates |
| In qualification | Evidence collection and review in progress |
| Operationally approved | All applicable gates passed and evidence filed |
| Conditional | Limited approval with a named closure action |

---

## 7. Evidence Minimums by Supplier Type

| Supplier Type | Minimum Evidence |
|---------------|------------------|
| Imported long-lead equipment / components | Technical datasheet, commercial quote, lead-time commitment, CoC path |
| Hazardous / regulated materials | MSDS, permit path, handling requirements, logistics plan |
| Intragroup suppliers | SLA, quality gate, call-off process, escalation path |
| Local packaging / fabrication suppliers | Quality questionnaire, sample approval, lead-time commitment |
